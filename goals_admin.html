TikTok · Acceso oficial

Requiere una app aprobada con user.info.stats. TikFinity por sí solo no da el total real de seguidores. Las credenciales se guardan en AppData, nunca se devuelven al navegador.

Kick · Fuente opcional

La API oficial no informa el total. Puedes agregar una fuente HTTPS propia que devuelva JSON como {"followers_count":123}. Se identifica como externa, no verificada; deja vacío si no dispones de una.

Frecuencia

Twitch usa Twitch Control existente (token válido; para consultar nombres requiere moderator:read:followers). Kick sin fuente externa conserva el valor manual y suma follows, pero no detecta unfollows.
