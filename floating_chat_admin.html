BRYNN INTERACTIVE SYSTEM

Chat flotante

Chat persistente Twitch + TikTok, transparente, siempre encima y con click-through.

Diseño HTML/CSS/JS del chat

Ventana

Puedes redimensionarla arrastrando la esquina. Desde V0.45 el tamaño manual se conserva al cerrar y volver a abrir.

Envío de mensajes

La app usa sendChat de Social Stream Ninja. Para que Twitch/TikTok acepten el envío, en SSN debe estar activado Global settings → Mechanics → Enable remote API control of extension y las cuentas deben tener permiso para escribir.

Comandos / atajos globales

Funcionan aunque el juego tenga el foco. Ejemplo: Ctrl+Alt+C.

Moderación

Bloquear en SSN/Brynn funciona mediante Social Stream Ninja. Para ban/timeout nativo de Twitch puedes habilitar Twitch Control. El token se guarda fuera de la carpeta web.

En la ventana flotante

Haz clic derecho sobre un mensaje para copiar usuario, bloquearlo en SSN/Brynn, aplicar timeout o ban en Twitch. El menú del navegador ya no debe aparecer.
