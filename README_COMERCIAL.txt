BRYNN INTERACTIVE V0.59.0 - BETA
COMMERCIAL FOUNDATION
========================================

Esta edición está preparada para distribuirse sin datos personales del desarrollador.

PRIMER INICIO
- Muestra un asistente limpio.
- Pide nombre del canal y, opcionalmente, cuentas propietarias Twitch/TikTok.
- Social Stream Ninja puede configurarse ahora o después.
- Modo Developer es opcional.

DATOS DEL USUARIO
Se crean localmente en:
%APPDATA%\BrynnInteractive\

El paquete comercial NO debe contener:
- tokens de Twitch / Streamlabs
- Session ID o password privado de SSN
- webhook keys activas
- ranking / economía reales
- emotes o multimedia privados
- backups o logs del desarrollador

DATOS Y PRIVACIDAD
Dentro de la app existe un apartado para:
- exportar configuración (sin tokens privados)
- importar configuración
- crear backups
- borrar ranking/economía
- restablecer completamente la aplicación

BUILD COMERCIAL
Ejecuta:
  crear_build_comercial.bat

El proceso genera una copia limpia y ejecuta un escaneo automático antes de permitir la distribución.
